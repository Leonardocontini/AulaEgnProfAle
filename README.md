🧑‍💻 A História do Git (jeito informal)
🐣 Tudo começou lá em 2005...

Era uma vez um cara chamado Linus Torvalds — sim, o mesmo criador do Linux. Naquela época, a galera do kernel do Linux estava usando um sistema chamado BitKeeper pra versionar o código.

Só que deu ruim. 😬

💥 Treta com o BitKeeper

O BitKeeper era um sistema de controle de versão proprietário, ou seja, não era de código aberto. A comunidade usava "de graça", mas tinha algumas regrinhas.

Um dia, o dono do BitKeeper ficou pistola porque alguém da comunidade começou a tentar fazer engenharia reversa no software. Resultado? Puxaram o tapete. Tiraram o acesso gratuito e... 💣 caos.

🧠 Linus pensou: “quer saber? Vou fazer o meu!”

Linus não ficou chorando não. Ele foi lá e pensou:

“Preciso de um sistema de controle de versão que seja rápido, distribuído e seguro.”

E aí nasceu o tal do Git. O nome “Git” é meio zoado mesmo — em inglês britânico, pode significar algo tipo "idiota", e o próprio Linus falou que escolheu o nome porque ele é um pouco arrogante. 😅

⚙️ Como o Git foi feito?

Linus criou o Git com algumas ideias bem massa:

Velocidade: nada de sistema lento!

Distribuído: cada dev teria uma cópia completa do repositório.

Integridade: tudo versionado, com segurança usando SHA-1.

Sem depender de ninguém: open source e livre!

🚀 Git se espalhou rapidinho

Depois que o Git ficou estável (tipo... em semanas!), a própria galera do kernel do Linux começou a usar.

E daí em diante... o resto é história:

Projetos open source começaram a adotar

Vieram plataformas como o GitHub, GitLab, Bitbucket

Virou padrão de mercado

Hoje, se tu for dev e não souber Git... boa sorte! 😅

🧾 Resumão:
Ano	O que rolou
2005	BitKeeper deu ruim
2005	Linus criou o Git
2005 (mesmo ano!)	Comunidade do Linux começou a usar
2008+	GitHub surgiu e popularizou o Git ainda mais
🤓 Curiosidades

Linus só manteve o Git por uns 3 meses. Depois passou o bastão pro Junio Hamano, que toca o projeto até hoje.

Git não é um acrônimo. É só um nome engraçado mesmo.

O Git salva tudo como snapshots, não como deltas. Isso deixa ele super rápido.
